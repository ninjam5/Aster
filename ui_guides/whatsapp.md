# WhatsApp Desktop UI Guide

## Layout
- Left panel: contact/chat list with names and last message preview
- Right panel: active chat with messages
- Top of right panel: contact name and status — display only, NOT a button
- Bottom of right panel: message input field

## Navigation
- To open a chat: click the contact name in the LEFT PANEL
- After clicking, chat opens on the right and name appears in the top header — you are IN the chat
- Do NOT click the name in the top header

## Typing and sending
- Click the message input at the bottom of the right panel OR use type_text() if focused
- Press enter to send

## Common element text labels
- Search bar: "Search or start new chat"
- Message input: click in the typing area at the bottom right
- New chat: pencil icon at top left
