# Google Chrome UI Guide

## Layout
- Top bar: back/forward arrows, refresh, address bar (shows current URL), bookmark star, extensions
- Tab bar: row of open tabs just above the address bar — click a tab label to switch
- New tab: + button at the right end of the tab bar
- Main area: web page content

## Navigation
- Address bar: click it to type a URL or search query, then press enter
- Tabs: click the tab's title text to switch to it
- Back: click the left arrow at top-left or press Alt+Left

## Common element text labels
- Address/search bar: shows current URL — click to edit
- New tab: "+" at end of tab strip
- Bookmarks bar: text labels just below address bar (if visible)
