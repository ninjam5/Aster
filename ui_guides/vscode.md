# VS Code UI Guide

## Layout
- Left activity bar: icons for Explorer, Search, Source Control, Extensions
- Left sidebar panel: file tree (Explorer) or search results
- Main editor area: open file tabs at the top, code below
- Bottom status bar: branch name, line/col, language mode
- Terminal panel: at the bottom (toggle with Ctrl+`)

## Navigation
- Open file: click filename in Explorer sidebar
- Switch tab: click the tab label at the top of the editor
- Command palette: Ctrl+Shift+P or type label ">" in the search bar

## Common element text labels
- File explorer: "Explorer", "EXPLORER"
- Search: "Search", magnifier icon
- Extensions: "Extensions"
- Terminal: "Terminal" in bottom panel tab
